# 人生导航系统（Life Navigation System）· 开源模板

一个把「能力」原子化、把「选择」存档化的个人导航系统。不是主页，不是作品集——它是**你和自己未来焦虑的对抗工具**。

## 核心理念

1. **能力原子化**：把能力拆成最小可迁移单元（抽象定义 + 实证场景 + 可迁移方向 + 原子间连接）。学新东西前先查库——能复用的直接复用，缺口单独补，与主线无连接的一律不碰。避免能力冗余。
2. **决策存档化**：每个做过终裁的人生岔路口记一条（当时情境 / 终裁 / 理由 / 锁定期 / 反悔条件）。防止未来的自己在焦虑中篡改历史，也不用重算一遍。
3. **缺口 = 清单 = 最小行动**：目标岗位能力画像对比「市场要求 vs 我的现状」，只记录事实，不做自我评判。

## 五个页面

| 页面 | 作用 |
|---|---|
| 总览 | 职业主干时间轴、已裁定岔枝、能力三层分布、本季度聚焦 |
| 能力图谱 | 能力原子卡片，按领域 / 三层 / 状态筛选 |
| 迁移地图 | 原子连接关系图——连线越密的原子越值得优先复用 |
| 缺口分析 | 目标岗位缺口画像 + 「任意课题接入」：输入想学的课题，自动匹配可复用原子、列出缺口、提醒你不要回头去捡已砍的 |
| 决策日志 | 每个终裁的完整存档 |
| 审计 | 每月 15 分钟：弱连接原子三选一裁决（强化 / 降级 / 砍掉），已砍清单防回流 |

## 快速开始（5 分钟拥有自己的系统）

### 方式一：直接用 GitHub 模板（推荐）

1. 点本仓库右上角 **Use this template → Create a new repository**（如果看不到这个按钮，让仓库所有者去 Settings 勾选最上面的 **Template repository**）
2. 仓库名随意（如 `my-life-nav`），**设为 Private**——你的决策记录是你的隐私
3. 仓库 **Settings → Pages → Source 选 GitHub Actions**（只需一次）
4. 等 Actions 跑完（约 2 分钟），访问 `https://<你的用户名>.github.io/<仓库名>/`
5. 把 `src/data/` 下三个文件的示例内容替换成你自己的记录（下面有写法）

### 方式二：本地跑

```bash
npm install
npm run dev      # 开发预览
npm run build    # 类型检查 + 构建，产物在 dist/
```

## 怎么填数据（99% 的日常更新只动三个文件）

**`src/data/atoms.ts` —— 能力原子库**
- 每个原子：`abstraction`（剥掉场景后的本质动作）、`evidence`（真实用过的场景，**只写真事**）、`transferableTo`（可迁移方向）、`keywords`（课题接入的命中词）、`connections`（连接哪些原子）、`level`（1-5）、`status`（core 核心 / active 活跃 / weak 弱连接 / pruned 已砍）
- 三层分类：专业壁垒（护城河）/ 个人品牌（外表谈吐）/ 个人品质（软实力）
- 写完新原子，记得把它挂进相关原子的 `connections`，迁移地图的连线才会出现

**`src/data/profile.ts` —— 目标岗位缺口画像**
- `PROFILE_META`：目标岗位、城市、数据来源、更新日期
- 每个维度：市场要求（从 JD 高频词整理）/ requiredLevel / currentLevel（基于实证不是感觉）/ fact / nextAction（最小行动）/ priority

**`src/data/decisions.ts` —— 决策日志**
- 复制示例条目改内容即可。一条合格决策 = 当时情境（事实不带情绪词）+ 终裁（一句话）+ 理由（写给半年后焦虑的自己）+ 锁定期（可选）+ 反悔条件（硬证据，不是情绪）

改完推送 main，Actions 自动重新部署，1-2 分钟线上更新。

## ⚠️ 隐私提醒

- 建议仓库**保持私有**。决策日志里都是你的人生真实记录。
- 公开分享时建议只分享方法（本 README 和页面截图），不要公开你的数据仓库。
